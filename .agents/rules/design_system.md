# KB Growth Design System & Aesthetics

When building or modifying UI components, strictly adhere to the following design principles to maintain a "Clean & Amazing" premium aesthetic:

1. **Typography**: Always use **Plus Jakarta Sans** as the universal font family. Avoid mixing in `font-mono` or `font-display` utility classes unless explicitly building code snippets or specialized data displays.
2. **The "Soul" (Black/Purple Theme)**: The brand identity relies on a high-contrast Black, White, and Purple palette. Never strip the site down to pure monochrome minimalism. Use purple accents (e.g., `#ddb7ff`, `#b76dff`) strategically for text gradients, active states, and subtle background glows.
3. **Refined Glows & Gradients**: Avoid heavy, jarring neon glows and highly opaque mesh gradients. Background blurs and mesh gradients should be ambient and subtle (e.g., `< 10%` opacity). Button glows should be tight and sophisticated, utilizing drop-shadows rather than massive CSS halos.
4. **Clean Architecture**: Flatten "bento box" layouts. Use solid dark surfaces (e.g., `#111111`, `#141414`), ultra-thin `1px` borders (`border-white/5` or `border-white/10`), and generous whitespace padding. Avoid inner shadows and muddy glassmorphism.
